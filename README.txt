YASH GUPTA - PORTFOLIO
======================
Open index.html in a browser. No build step needed.

Folders
  index.html        all page content (edit text, dates, links here)
  css/style.css     colours and layout (accent gradient is --accent at the top)
  js/main.js        hero animation, hover/tap colour, lightbox
  assets/           profile.jpg, resume, offer letter, certs/, projects/

Add real project screenshots
  Save 1280x800 screenshots as:
    assets/projects/parakh.jpg
    assets/projects/anstaa.jpg
    assets/projects/smartbin.jpg
  They replace the drawn placeholder previews automatically.

Dates
  Check the timeline in index.html. The 2026 IEEE WIE ILS and
  IEEE SPS entries have approximate dates.

Publish for free
  Netlify: drag this whole folder onto app.netlify.com/drop
  GitHub Pages: push the folder to a repo, then Settings > Pages.
